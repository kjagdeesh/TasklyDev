TasklyDev third-party notices
=============================

The TasklyDev application contains no third-party NuGet libraries or separately
bundled third-party assets. Its own assemblies are the TasklyDev application,
core, and Windows assemblies.

This self-contained build also includes the Microsoft .NET 10 runtime and
Windows Desktop (WPF) runtime that the application runs on. Those Microsoft
components are subject to Microsoft's applicable license terms, available from
the .NET project at https://github.com/dotnet/runtime and
https://github.com/dotnet/wpf.

The test project uses xUnit and Microsoft.NET.Test.Sdk packages. Those
development/test dependencies are not included in the application publish
output.
